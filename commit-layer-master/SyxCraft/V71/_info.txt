## Engine Changes (Reign of Terror)

### Laws & Government System
- **NEW:** Law Categories (Civic, Criminal, Military, Economic, Religious)
- **CHANGED:** Law enactment now requires Government Points (GP) + specific building tiers
- **CHANGED:** Law enactment UI completely redesigned

### Slavery System Overhaul
- **CHANGED:** Slavery is now a Law Category (Criminal) with tiers
- **CHANGED:** Enslavement chance based on Law Tier + Crime Severity
- **CHANGED:** Slaves are now a Population Class (not just resource)
- **CHANGED:** Slave Trade is now Diplomatic Action (requires Embassy + Trade Agreement)
- **REMOVED:** `SLAVE_PRICE` property from Race definition (now dynamic via Law)

### Population Growth System
- **CHANGED:** Growth Formula: `BASE_GROWTH * CLIMATE_MOD * TERRAIN_MOD * HOUSING_MOD * LAW_MOD`
- **CHANGED:** `POPULATION.GROWTH` stat is now a multiplier (1.0 = vanilla)
- **CHANGED:** `POPULATION.MAX` is now dynamic (Housing + Infrastructure)
- **NEW:** `POPULATION.GROWTH` can be negative (population decline)
- **NEW:** Migration system reworked (Immigration/Emigration as separate flows)

### Race Relations
- **CHANGED:** `OTHER_RACES` liking now affects Migration + Trade + Diplomacy
- **NEW:** Race-specific Laws possible (e.g., "Undead Labor Act")
